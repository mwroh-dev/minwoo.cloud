# i18n Rules

## Locale handling

- In renderer code, do not branch on raw `'ko'` or `'en'` strings.
- Use locale constants, locale helpers, and typed locale values from `src/lib/i18n.ts`.

## Localized paths and labels

- Use centralized helpers for localized archive/detail paths.
- User-facing locale labels should come from i18n maps, not ad-hoc inline strings.

## External and internal URLs

- Keep important URLs in named constants or helpers.
- Route paths that depend on locale should be produced by helpers, not string concatenation inside JSX.
